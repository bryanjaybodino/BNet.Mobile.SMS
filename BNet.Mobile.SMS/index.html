REST API Documentation

HTTP Request Endpoints

Standard JSON HTTP endpoints for integrating SMS dispatch into any Web or Desktop Application.
Note: Default Server Port is 8030. Replace "192.168.1.X" with your Phone's active IP address.

GET http://192.168.1.X:8030/status

1. API Status Check

Checks whether the SMS API service is running and reachable on the local Android phone server. 

// Replace with Android Phone's Local IP
const API_BASE_URL = "http://192.168.1.15:8030";

const checkStatus = async () => {
    try {
        const res = await fetch(API_BASE_URL + "/status");
        const data = await res.json();
        console.log(data);
    } catch (error) {
        console.error("SMS Gateway Offline", error);
    }
};

checkStatus();
POST http://192.168.1.X:8030/send

2. Send SMS Payload

Sends SMS to single or comma-separated multiple phone numbers via standard JSON request body. 

// Replace with Android Phone's Local IP
const API_BASE_URL = "http://192.168.1.15:8030";

const payload = {
    receiver: "09123456789,09223334444",
    message: "Hello from Android SMS API!"
};

const sendSms = async () => {
    const res = await fetch(API_BASE_URL + "/send", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(payload)
    });
    const result = await res.json();
    console.log(result);
};
Database Sync Setup

Storing SMS to MySQL

Automatically forward and record incoming SMS messages straight to your local XAMPP or remote MySQL database table.

1
XAMPP MySQL Setup Install XAMPP, start MySQL service, and disable Windows Firewall for local network access.
2
User Privileges & Hostname Set MySQL Hostname wildcard to % and enable Grant all privileges for the Android connection.
MYSQL CONNECTION STRING XAMPP / MYSQL

Paste this connection string format into your Android app connection settings:

server=192.168.1.1;port=3306;uid=Your_Username;password=;database=Your_Database
