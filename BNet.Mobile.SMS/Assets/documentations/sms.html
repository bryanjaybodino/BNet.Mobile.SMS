SMS API Documentation

This API provides endpoints to check API status and send SMS messages using standard HTTP requests.

API Status Check

Endpoint
GET /status
Description

Checks whether the SMS API service is running and reachable.

JavaScript Example

const checkStatus = async () => {
    try {
        const response = await fetch(API_BASE_URL + "/status");
        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.error("API is not reachable", error);
    }
};

checkStatus();

Send SMS

Endpoint
POST /send
Request Headers

Content-Type: application/json
Request Body
  • receiver – Recipient phone number
  • message – SMS message content

Notes : For multiple recipients, separate the numbers with commas.

JSON Example


{
    "receiver": "09123456789,09223334444",
    "message": "Hello World"
}
JavaScript Example

const payload = {
    receiver: phoneNumber,
    message: message
};

const sendSms = async () => {
    try {
        const response = await fetch(API_BASE_URL + "/send", {
            method: "POST",
            headers: {
                "Content-Type": "application/json"
            },
            body: JSON.stringify(payload)
        });

        if (!response.ok) {
            throw new Error("Failed to send SMS");
        }

        const result = await response.json();
        console.log("SMS sent successfully", result);
    } catch (error) {
        console.error("Error sending SMS", error);
    }
};

sendSms();
Notes
  • Ensure the API server is running before sending SMS.
  • The device must have a valid SIM card configured.
  • If hosted locally, client and server should be on the same network.
