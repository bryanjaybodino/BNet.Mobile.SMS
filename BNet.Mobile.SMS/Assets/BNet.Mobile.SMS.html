SMS API Documentation

This API provides endpoints to check API status and send SMS messages using standard HTTP requests.

API Status Check

Endpoint
GET /status
Description

Checks whether the SMS API service is running and reachable.

JavaScript Example

const checkStatus = async () => {
    try {
        const response = await fetch(API_BASE_URL + "/status");
        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.error("API is not reachable", error);
    }
};

checkStatus();

Send SMS

Endpoint
POST /send
Request Headers

Content-Type: application/json
Request Body
  • receiver – Recipient phone number
  • multiple recipients – separate numbers with commas "09123456789,09223334444"
  • message – SMS message content

JSON Example


{
    "receiver": "09123456789,09223334444",
    "message": "Hello World"
}
JavaScript Example

const payload = {
    receiver: phoneNumber,
    message: message
};

const sendSms = async () => {
    try {
        const response = await fetch(API_BASE_URL + "/send", {
            method: "POST",
            headers: {
                "Content-Type": "application/json"
            },
            body: JSON.stringify(payload)
        });

        if (!response.ok) {
            throw new Error("Failed to send SMS");
        }

        const result = await response.json();
        console.log("SMS sent successfully", result);
    } catch (error) {
        console.error("Error sending SMS", error);
    }
};

sendSms();
Notes
  • Ensure the API server is running before sending SMS.
  • The device must have a valid SIM card configured.
  • If hosted locally, client and server should be on the same network.

Storing SMS to MySQL

This guide explains how to configure MySQL so the application can store incoming SMS messages into your database.

Setup Instructions
  1. Install XAMPP and enable MySQL
  2. Turn off your Firewall (for local network access)
  3. Create any database name
  4. Select your database
  5. Open Privileges
  6. Add a new user account
Login Information
  • Username: Use text field → your credentials
  • Hostname: Any host → %
  • Password: Optional
Database Permissions

Check Grant all privileges on your selected database.

Global Privileges

Enable all privileges.

MySQL Connection String

Copy and replace the credentials below in your application settings. 

server=192.168.1.1;port=3306;uid=Your_Username;password=;database=Your_Database
